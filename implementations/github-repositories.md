# GitHub Implementations

This file contains GitHub repositories that provide practical implementations related to **citation extraction, citation verification, scientific document processing, and hallucination detection**.

The repositories were selected based on relevance to the research topic, availability of source code/documentation, reproducibility, and connection to scholarly research or citation-integrity workflows.

---

## 1. GROBID

**Repository:** `kermitt2/grobid`  
**What it implements:** Machine-learning-based parsing of scientific PDFs into structured scholarly information.

### What It Does

GROBID can extract and structure:

- Article metadata
- Titles
- Authors
- Abstracts
- Sections
- Bibliographic references
- Citation callouts
- Citation contexts
- DOI and PMID information

It can also resolve extracted bibliographic references through services such as Crossref.

### Why It Is Relevant

Citation-drift detection requires extracting references and citation contexts from an AI-generated research paper before those citations can be verified.

GROBID can therefore form the **document-processing stage** of a citation-integrity pipeline.

### Example Workflow

```text
Research Paper PDF
       |
       v
     GROBID
       |
       +----> Paper metadata
       |
       +----> References
       |
       +----> Citation contexts
       |
       v
Bibliographic verification
```

### Official Repository

[GitHub: kermitt2/grobid](https://github.com/kermitt2/grobid)

### License

Apache License 2.0.

### Verification

The official project documentation describes GROBID as software for extracting, parsing, and restructuring scientific documents, including references and citation contexts. It also documents DOI/PMID resolution using bibliographic services. citeturn0search0

## 2. BibTeX Hallucination Detector

**Repository:** `stvsun/bibtex-verifier`  
**What it implements:** Automated verification of BibTeX references against scholarly databases.

### What It Does

The tool reads BibTeX bibliography entries and checks them against:

- Crossref
- Semantic Scholar

For each reference, it compares bibliographic information using a weighted matching process involving:

- Title similarity
- Author overlap
- Publication year
- Venue similarity

It can flag potentially fabricated or hallucinated bibliography entries and generate a corrected BibTeX file.

### Why It Is Relevant

This is one of the most directly relevant implementations for the research topic.

AI-generated research papers frequently contain references that look realistic but may contain:

- Fabricated papers
- Wrong titles
- Wrong authors
- Incorrect years
- Incorrect venues
- Invalid DOI information

This repository automates many of the metadata checks required in the earlier citation-integrity audit.

### Example Workflow

```text
BibTeX file
    |
    v
BibTeX Hallucination Detector
    |
    +----> Crossref search
    |
    +----> Semantic Scholar search
    |
    v
Metadata similarity scoring
    |
    v
Potentially fabricated references
```

### Official Repository

[GitHub: stvsun/bibtex-verifier](https://github.com/stvsun/bibtex-verifier)

### Why It Is Especially Useful

It closely matches the repository's central research question:

> Can an AI-generated citation be independently verified against authoritative scholarly metadata?

The project README explicitly describes it as a BibTeX hallucination detector for references generated by LLMs. citeturn0search8

## 3. xRef

**Repository:** `kazilab/xRef`  
**What it implements:** Cross-database bibliographic reference verification.

### What It Does

xRef checks bibliography metadata against multiple scholarly services, including:

- DOI.org
- PubMed
- Europe PMC
- Crossref
- OpenAlex
- Semantic Scholar

It compares bibliographic fields such as:

- Authors
- Title
- Journal
- Year
- Volume
- Issue
- Pages
- DOI
- PMID

### Why It Is Relevant

The previous citation-integrity assignment required checking whether AI-generated references were genuine and whether their metadata matched authoritative records.

xRef provides an implementation of that verification idea.

### Official Repository

[GitHub: kazilab/xRef](https://github.com/kazilab/xRef)

### Example Use

```text
AI-generated bibliography
          |
          v
         xRef
          |
    +-----+-----+-----+-----+
    |     |     |     |     |
 Crossref OpenAlex PubMed  S2
    |     |     |     |     |
    +-----+-----+-----+-----+
          |
          v
 Metadata comparison
          |
          v
 Verification result
```

### Relevance to Research

xRef demonstrates why citation verification should ideally use **multiple independent scholarly databases** rather than relying on the AI system that generated the citation.

## 4. SciFact

**Repository:** `allenai/scifact`  
**What it implements:** Scientific claim verification using evidence from research papers.

### What It Does

The SciFact project provides code, data, and evaluation resources for scientific claim verification.

The task involves determining whether scientific evidence:

- Supports a claim
- Contradicts a claim

The system also works with evidence rationales identifying the relevant evidence.

### Why It Is Relevant

Citation integrity has two different levels:

1. **Citation existence:** Does the cited paper actually exist?
2. **Claim support:** Does the cited paper actually support the claim?

SciFact is particularly useful for the second problem.

### Example Workflow

```text
Generated claim
      |
      v
Retrieve scientific evidence
      |
      v
Compare claim and evidence
      |
   +--+--+
   |     |
SUPPORT CONTRADICT
```

### Official Repository

[GitHub: allenai/scifact](https://github.com/allenai/scifact)

### Associated Research

*Fact or Fiction: Verifying Scientific Claims* was published at EMNLP 2020.

### Relevance to Citation Drift

SciFact can support research into **claim-citation alignment**, where a system checks whether the evidence contained in a cited paper actually supports the generated statement.

## 5. HALIFacts

**Repository:** `theophilem-acelys/HALIFacts`  
**What it implements:** Training and evaluation framework for LLM-based scientific and biomedical fact checking.

### What It Does

HALIFacts provides code for training and evaluating LLMs on scientific and biomedical fact-checking tasks.

The repository includes:

- Training scripts
- Evaluation scripts
- Dataset support
- Model configuration
- Fact-checking experiments
- Carbon tracking functionality

The project documentation demonstrates use with the SciFact dataset.

### Why It Is Relevant

Citation-drift detection is closely related to scientific fact checking. An AI-generated literature summary can contain a factual statement that appears plausible but is not supported by the cited evidence.

HALIFacts provides an implementation framework for studying this broader scientific fact-checking problem.

### Example Workflow

```text
Scientific claim
       |
       v
Fact-checking model
       |
       v
Evidence / dataset
       |
       v
Verification decision
```

### Official Repository

[GitHub: theophilem-acelys/HALIFacts](https://github.com/theophilem-acelys/HALIFacts)

### Research Connection

The project documentation describes it as an LLM training framework for scientific and biomedical datasets and provides training/evaluation code using SciFact. citeturn0search9

# How the Implementations Fit Together

The repositories can be combined conceptually into a complete research pipeline:

```text
                    AI-Generated Research Paper
                                |
                                v
                             GROBID
                                |
                 +--------------+--------------+
                 |                             |
                 v                             v
          Citation Extraction            Citation Context
                 |
                 v
          bibtex-verifier / xRef
                 |
                 v
       Bibliographic Verification
                 |
          +------+------+
          |             |
       Genuine       Suspicious
          |
          v
     SciFact / HALIFacts
          |
          v
     Claim-Evidence Verification
          |
          v
    Citation Integrity Decision
```

This separation is important because **a genuine publication is not automatically evidence that the generated claim is correct**.
